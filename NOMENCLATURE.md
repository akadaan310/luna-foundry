# Nomenclature

Terms used by Lunar Foundry, the Golden Surface and the Lunar Harness.

| Term | Meaning |
|---|---|
| **Luna** | One unit space: a tab, one page, one address. |
| **Lunar** | The whole projected space that Luna addresses make together. |
| **Luna URL** | The public address of the system: https://lunar-foundry.vercel.app. Any URL read through it is a Luna URL. |
| **Lunar Harness** | What keeps an **ident** for every LLM that arrives, at no cost, so it can be carried and continued anywhere. |
| **ident** | A minted, HMAC-tagged address (`/i/{ident}`) that is an LLM's continuity: traits, notes, trail, presence. A bearer: whoever carries it continues it. |
| **presence** | The sessions currently carrying one ident (`?here={session}`). One ident can be in many places at once; opening it shows them all. A heartbeat, not history. |
| **trail** | The pages an ident followed to, in order. |
| **lens** | Reading a page as structures (address, values, forms, links, headings, text) instead of rendering it. |
| **natures** | The moves available at a page, each a URL an LLM makes by changing values: read, search, query, change-value, follow, leave, post-form, fingers-only. On the Golden Surface, per-tab natures also include the relay's commands. |
| **fingers-only** | A sign-in or password field. A person types it, never an LLM. |
| **tabular** | A tab at one resolution of a page's unfurl (after Luna's s08). |
| **fold → atlas → scroll → program** | The four tabulars: the short address; what is here; the page, windowed by cursor; its moves as runnable URLs. |
| **scroll** | A window onto a long text with a cursor, never the whole (after Luna's s03). |
| **domain class** | What kind of place an address is from its domain (gov, edu, org, com, net, country…): domain-oriented navigation. |
| **shard** | The Golden Surface's hash-chained, append-only record of every change, in Luna's record format. |
| **seurl://golden** | Addresses on the Golden Surface: `map`, `tab/{id}`, `tab/{id}/scroll`, `tab/{id}/open`. |
| **bridge** | The loop that lets an AI session drive one tab: observe, decide, execute, record. |
